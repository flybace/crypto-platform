# 使用手册

Crypto Multi-Market Quant Platform（以下简称本系统）是一套数字资产多市场量化研究与模拟交易系统：行情、历史数据、回测、调参、策略准入、币池、模拟盘、风控在一个工作台里闭环。

**一句话主链路**：历史数据 → 回测/调参 → 策略准入 → 启动策略 → 独立策略引擎 → 模拟账户自动下单 → 绩效与风控。

> 安全底线：服务端执行模式固定为 `DISABLED`，真实下单路径不可达；所有自动下单都发生在**模拟账户**；真实账户只支持只读接入。

---

## 1. 安装与启动

需要 [Docker](https://docs.docker.com/get-docker/)（Windows 用 Docker Desktop）。

```bash
# Linux / macOS
curl -fsSL https://raw.githubusercontent.com/flybace/crypto-platform/main/install.sh | bash
```

```powershell
# Windows PowerShell
irm https://raw.githubusercontent.com/flybace/crypto-platform/main/install.ps1 | iex
```

仓库是私有时，先生成只读 token（GitHub → Settings → Developer settings → Personal access tokens → Fine-grained，`Contents: Read-only`，仅选本仓库）：

```bash
export GITHUB_TOKEN=你的token
curl -fsSL -H "Authorization: Bearer $GITHUB_TOKEN" \
  https://raw.githubusercontent.com/flybace/crypto-platform/main/install.sh | bash
```

安装脚本会自动拉代码、生成 `.env`（随机管理员密码，仅显示一次）、构建启动。装好后打开 http://127.0.0.1:4191 登录。

- 重复运行脚本 = 更新到最新版
- 停止：`docker compose stop`；卸载：`./uninstall.sh`（加 `--purge` 连数据一起删）

## 2. 功能模块说明

### 总览（交易驾驶舱）

打开即看的决策面板：

- **资产条**：模拟总权益、运行中策略数、累计下单、市场状态（分数与仓位系数）
- **策略健康度**：每个实例的运行状态、准入评级、最近信号
- **待办事项**：自动聚合——市场禁开仓警告、风控事件、未评级策略提醒

### 历史数据

- 从 Binance / OKX / Bybit 拉取 K 线（1d / 1h / 5m），手动同步或定时增量
- 每份数据集有**质量门禁**（缺口、重复校验），不合格的数据不进回测
- 数据覆盖页显示各市场各品种的同步状态

### 行情

- 三家交易所现货行情并排对比（A 股式紧凑表格，红涨绿跌）
- 搜索、排序、分页，10 秒刷新；点击行看 K 线详情

### 回测

- 选策略 + 币池 + 时间范围 + 手续费/滑点/止损止盈，跑历史回测
- 结果含收益、回撤、胜率、夏普、权益曲线、成交明细
- **自动调参**：批量试参数，带过拟合检查（训练+验证窗口都要为正才算过）
- 调参最优参数可一键应用到模拟盘（未过过拟合检查会弹确认框）

### 策略与准入漏斗

每个策略版本是"档案 + 参数哈希"的版本化资产，防止调参调出不可复现的结果。

- 每次回测提交生成档案号（`run-xxx`）和 SHA256 参数哈希
- 评级 S / A / B / C / D（综合收益、回撤、胜率、夏普、样本量）
- 晋级漏斗：评分 → 同规格复测 → 跨池验证 → 模拟盘准入，**只晋级不降级**
- **模拟盘硬门槛**：A 级及以上才能启动，已有实例不受追溯影响

### 币池

```text
行情 → 筛选 → 候选池 → 人工确认 → 交易池 → 策略实例 → 模拟下单
```

- 三种池：**手动**、**24h 成交额 TopN**、**近 7 天低波动**（动态池每小时自动刷新）
- **权限分层**：新池一律是候选池，只能研究/回测；人工点"确认"升级为交易池后，策略实例才能选用
- 每次刷新保存**成分快照**，回测可按时间点取成分，避免未来函数
- 策略实例可选用整个交易池，逐币运行（每个币独立模拟账户）

### 模拟盘

- 多策略多实例：每个实例独立配置、独立模拟账户、独立状态文件
- 策略引擎每 60 秒轮询全部启用实例，读最新已收盘 K 线，有信号就自动下单（模拟）
- 支持"立即执行"手动触发一轮；支持重置单个实例的模拟账户
- 每个实例可配三道风控：**持仓上限**、**止损**、**单日最大亏损**（触发后停牌至次日 UTC 0 点）

### 风控与市场状态

- 以 BTC/USDT 日线评估市场状态：相对 MA60 趋势、连涨跌天数、60 日回撤、波动率
- 偏强 ×1.0 / 中性 ×0.6 / 偏弱 ×0.3 / 危机 ×0.0（禁止开仓）
- 数据不可用或质量门禁失败时强制危机；**只拦截买入，卖出永不拦截**
- 模拟盘顶部横幅实时显示市场状态

### 账户（真实账户只读）

- 在账户页填写 Binance API Key / Secret（**只需要读取权限**，不要给交易/提现权限）
- 密钥存 0600 权限文件，永不回显；保存后自动验证连通性，失败自动回滚
- 只读功能：余额快照、账本、对账（定时比对账实差异）
- 真实下单功能未实现，执行模式保持 DISABLED

### 其他模块

- **筛选**：按策略在币池上跑信号筛选
- **孵化池**：未达准入的策略先放孵化观察
- **建议**：信号分层（主推荐 / 观察池 / 暂不建议）
- **任务**：后台任务（拉数、回测、调参）的统一监护
- **通知**：事件推送配置
- **系统**：外观主题（深色/浅色）、用户管理
- **网络设置**：每家交易所独立的 REST / WebSocket 地址与代理配置
- **新闻 / AI 能力**：已暂停开发，页面保留

## 3. 典型工作流

**从零到一个跑起来的模拟策略**：

1. **历史数据**页：同步 BTC/USDT（或目标币种）的 1h 数据，等质量门禁通过
2. **回测**页：选策略（如 `macd_reversal`）、设参数、跑回测，看收益/回撤/胜率
3. 不满意就去**自动调参**，找到过拟合检查通过的参数，一键应用
4. 回测结果**提交到准入漏斗**，按 评分 → 复测 → 跨池验证 晋级到 A 级
5. **币池**页：建个 TopN 池或手动池，人工确认为交易池（单币种可跳过）
6. **模拟盘**页：添加策略实例（选策略+A级参数+币池），点启动
7. **总览**页盯驾驶舱：市场状态、策略健康、待办事项

## 4. 安全说明

- `CRYPTO_EXECUTION_MODE=DISABLED` 是服务端强制默认值，真实下单代码路径不存在
- 自动交易是**两级开关**（与门），都默认关闭：账户页的"自动交易"总开关 × 模拟盘每个策略实例的"自动交易"开关。两者同时打开，策略信号才会自动下模拟单；任一关闭时引擎只记录信号、不下单（含止损单）。模拟盘的"自动下单"指模拟账本，不涉及真实资金
- 交易所 API Key 只申请**读取**权限；Secret 以 0600 文件保存，API 永不返回
- 调参只能证明"历史上不过拟合"，不保证未来盈利——不要拿真钱直接上

## 5. 常见问题

- **模拟盘一直没下单**：先看总览驾驶舱——市场状态是否禁开仓、策略是否有信号、实例是否启用。无信号不下单是正常的。另外检查两级自动交易开关：账户页总开关和策略实例开关必须同时打开，否则信号只记录不下单。
- **策略启动被拒绝**：看报错——通常是准入漏斗评级不够（需要 A 级）或选了候选池（需要先人工确认为交易池）。
- **回测跑不起来**：检查历史数据质量门禁是否通过，时间范围是否有数据。
- **Docker 内存不足**：首次构建需要 2GB+ 可用内存；`docker compose logs -f` 看日志。
