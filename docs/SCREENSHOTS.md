# 截图清单（开源 README 配图）

> 目标：给 README 顶部加 3–5 张产品截图，让人一眼看懂这是什么。
> 截图统一 1600×900（浏览器 F12 切设备尺寸或直接全屏截），存到 `docs/images/`，在 README 里引用。

## 必拍（按重要度排序）

| # | 页面 | 怎么拍 | 说明文案 |
|---|------|--------|----------|
| 1 | 总览（数据大屏） | 左侧导航点「总览」，等曲线加载出来 | 数据大屏：KPI、组合权益曲线、策略排行 |
| 2 | 模拟盘 + 绩效弹窗 | 「模拟盘」页点某个实例的「绩效」按钮，弹窗完全展开 | 模拟盘实例绩效：权益曲线、回撤、胜率、成交 PnL |
| 3 | 任务中心 | 跑一个回测任务，切到「任务中心」，截正在运行的进度条 | 全系统任务中心：可视化进度条 |
| 4 | 回测 | 「回测」页跑完一次，截权益曲线 + 指标 | 回测：收益/回撤/胜率/夏普 |
| 5 | 行情 | 「行情」页三家交易所并排 | 三所行情并排对比 |

## 可选

- 策略准入漏斗（评级徽章）
- 币池（动态池列表）
- 历史数据（K 线质量门禁）

## 注意事项

- 截图前把浏览器书签栏隐藏（Ctrl+Shift+B），地址栏无所谓（本地地址）
- 涉及 API Key 的页面不要截（账户页 Secret 永不回显，但别截输入框）
- 模拟盘数据是模拟账户，无真实资金，可放心截
